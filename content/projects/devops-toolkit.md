## Overview

A collection of CLI tools I use daily for DevOps work.

## Features

- Kubernetes deployment helpers
- AWS resource management
- Log aggregation and search
- Quick SSH access to instances

## Installation

```bash
pip install devops-toolkit
```

## Usage

```bash
dt k8s deploy my-app
dt aws list-instances
dt logs search "error"
```
